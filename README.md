# Sipeng Chen — personal website

A static academic website with a deep navy background (#102a6b), white text, and warm gold contact icons (#cca273). Text is enlarged throughout. No installation or build is required.

## Files

- `dist/index.html`: About, News, Selected Publications.
- `dist/personal.html`: personal introduction.
- `dist/styles.css`: responsive styles, keyboard focus, reduced motion, print styles.
- `dist/assets/kitty_explains_to_sipeng.png`: favicon preserved from the original website; the About portrait has been removed.

## Use with GitHub Pages

The downloadable ZIP places the website files directly at its root. Upload `index.html`, `personal.html`, `styles.css`, and the `assets` folder to the root of `Sippengg/Sippengg.github.io` on the branch already used for GitHub Pages, replacing files with the same names. Preserve other repository files. Existing `script.js` is no longer referenced and can remain.

The current GitHub Pages website has not been modified by this workflow.
